# あんスタ!!Music イベント計算機

## enst-lab 入力アシスト（`assist.html`）

[enst-lab のイベントダイヤ計算機（ユニット新曲イベント用）](https://enst-lab.com/event.php) への入力を代わりに行う自分用ツールです。

下のタブバーで「スキャン／入力／設定」を切り替えるアプリ風の画面です。ホーム画面に追加すると全画面のアプリとして起動します（PWA）。

1. **スキャン**：スクショを入れて「読み取って入力する」。読み取った数字が画像の上にボタンで出るので、タップして「現在pt」などの項目を選ぶと入力されます。PASS・ホイッスルなど項目名が近くにある数字は自動で入ります。
2. **入力**：足りない数字を補う。上の円が必須項目の進み具合です。
3. 「enst-lab で計算する」で enst-lab に同じ内容を送信し、結果ページを新しいタブで開く

### 画像読み取りの方法（設定タブで切り替え）

| 方法 | 料金 | 特徴 |
| --- | --- | --- |
| 端末内OCR（標準） | 無料 | [Tesseract.js](https://github.com/naptha/tesseract.js) をブラウザ内で実行。画像は外部に送らない。初回に読み取りデータ（数MB）をダウンロード |
| Claude API | 従量課金 | 精度が高く、どの数字が何かも判断して自動入力。Anthropic の APIキーが必要（このブラウザの localStorage にだけ保存） |

- 計算そのものは enst-lab のサーバーで行われます。enst-lab 側のフォームが変わったら `assist.js` の項目定義（`DEFAULTS`・`ENST_EVENT_FLG` など）を合わせてください。
- イベント期間の判定（月末15:00〜8日21:59／15日15:00〜23日21:59）も enst-lab と同じロジックです。期間外は「イベント開始から」で計算します。

## オフライン計算機（`index.html`）

あんスタ!!Music のイベントで、目標ptまでの **残り曲数・必要BP・必要ダイヤ** を計算する静的Webツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。GitHub Pages などにそのまま置けます。

入力内容はブラウザの localStorage に自動保存されます。

## 計算内容

| 項目 | 計算 |
| --- | --- |
| 残り曲数 | `ceil((目標pt − 現在pt) ÷ 1曲あたりpt)` |
| 必要BP | `残り曲数 × 1曲の消費BP` |
| 使えるBP | `現在BP + 終了までの自然回復BP + その他の回復見込み` |
| 自然回復BP | 残り時間 ÷ 回復間隔。1日の放置時間のうち、BPが上限に達した後の分は取りこぼしとして差し引く |
| 必要ダイヤ | `ceil(不足BP ÷ 1回の回復BP) × 1回のダイヤ数` |

ほかに、所持ダイヤを全部使った場合の到達pt、消費BP（1〜10）ごとの曲数・ダイヤ・プレイ時間の比較表も表示します。

## ゲーム仕様の初期値

画面の「ゲーム仕様の設定」から変更できます。

- BP上限: 10
- BP回復: 30分で1
- ダイヤ回復: 20ダイヤで BP10
- 1曲の所要時間: 3分
- 獲得ptは消費BPに比例（×1〜×10）
